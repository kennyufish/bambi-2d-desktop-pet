# Cat model attribution

`cat_v2_tabby_plush.fbx` is an original procedural model generated for this
project with Blender. Its proportions and markings were derived from the
user-provided four-view tabby cat reference.

`cat_tabby_albedo_v2.png` was generated with OpenAI image generation from the
same reference. `cat_tabby_fur_tile_v2.png` is the Unity-ready seamless fur tile
derived from it and used as the baked short-fur surface texture.

The previous `cat.glb` / `cat.fbx` model remains in the source folder for
comparison. It is “Cat” by J-Toastie from Poly Pizza, licensed under CC BY 3.0:

https://poly.pizza/m/DJ9rpAhrh3
