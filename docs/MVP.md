# 3D 猫咪桌宠 MVP

## 目标

验证多角度照片能否在统一猫骨架上保留足够的身份特征，使主人一眼认出自己的猫。

## 首版范围

- Windows 10/11。
- 用户上传 3–5 张无遮挡、未穿衣服的猫咪照片。
- 五种标准体型：普通短毛、圆胖短毛、修长短毛、短腿猫、长毛毛绒版。
- 可调参数：胖瘦、脸宽、耳朵、腿长。
- 免费静态预览；付款后才运行真正的多图 3D 管线。
- 走动、坐下、趴下、睡觉、抚摸、拖拽、追鼠标和喂食。
- 花纹、眼睛或脸部纹理提供两次局部重新生成。
- 更换原始照片或猫咪视为新订单。
- 订单完成七天后删除原始照片和云端中间文件。

## 明确不做

- 多只猫同框、衣服或大面积遮挡。
- 无毛猫和需要改变标准骨架的身体缺损。
- 窗口边缘识别、麦克风或摄像头互动。
- 首版 macOS 客户端。

## 身份相似度验收

邀请 20 位猫主人参与盲测：

1. 每位主人提供符合要求的多角度照片。
2. 生成静态模型，不显示猫名。
3. 将模型与其他三只相似毛色的模型并列展示。
4. 至少 14 位主人应能在五秒内正确选出自己的猫。
5. 记录失败原因：花纹、脸型、眼睛、耳朵、体型或尾巴。

未达到 14/20 前，不扩展桌面互动功能。

## 生产管线

1. 图片质量检测与主体分割。
2. 猫咪关键点、体型和可见花纹分析。
3. 选择标准体型并应用参数化形变。
4. 多视角纹理投射、不可见区域补全和接缝修复。
5. 用户确认静态低清预览。
6. 付款后生成高清纹理和桌宠资源包。
7. Unity 客户端加载统一骨架与动作库。

## 单位经济目标

- 首发价格：US$4.99 测试价。
- 长期目标价格：US$6.99–$9.99。
- 单只平均云成本目标：不超过 US$1.50。
- 系统失败不计修正次数。
